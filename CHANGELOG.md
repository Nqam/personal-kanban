# История изменений (Changelog)

## [1.0.7] - 2026-11-20
### Улучшено
- При восстановлении дампа через системный проводник Android передаётся `DocumentsContract.EXTRA_INITIAL_URI` на провайдер Google Диска (`com.google.android.apps.docs.storage`), чтобы проводник открывался сразу в Google Диске.

## [1.0.6] - 2026-11-20
### Исправлено и улучшено
- В `AndroidManifest.xml` добавлена секция `<queries>` для `com.google.android.apps.docs` (обязательно для Android 11+ при прямой отправке дампа в Google Диск).
- В Настройках основная кнопка Google Drive переведена на прямую отправку/загрузку дампа через приложение Google Диск без ошибки 10.

## [1.0.5] - 2026-11-20
### Улучшено
- Кнопка «Сохранить дамп в Google Диск» теперь отправляет дамп напрямую в установленное приложение Google Диск (`com.google.android.apps.docs`) вместо открытия локальной файловой системы телефона.

## [1.0.4] - 2026-11-20
### Исправлено
- Устранён баг с `IntrinsicSize.Min` в `TaskCard` (заменён на `drawBehind`), из-за которого карточки задач могли не отображаться в некомпактном режиме.

## [1.0.3] - 2026-11-20
### Улучшено
- Иконка облака в шапке главного экрана открывает быстрое меню дампа в Google Диск (создать/сохранить дамп или скачать/восстановить дамп) без необходимости настройки Google Cloud Console и без ошибки 10.
- Диалог при первом запуске переведён на прямое создание/загрузку дампа в Google Диске.

## [1.0.2] - 2026-11-20
### Исправлено и улучшено
- Добавлены диалоги подтверждения при завершении и удалении задачи, увеличен порог свайпа (55%).
- Добавлен отступ `statusBarsPadding()` в шапке главного экрана, чтобы интерфейс не пересекался со строкой состояния телефона.
- Запрещено случайное закрытие окна создания задачи свайпом вниз (добавлена кнопка закрытия `×`).
- Выбор приоритета и статуса в окне создания задачи переведён на встроенные чипы (клавиатура не скрывается, кнопки срабатывают с первого нажатия).

## [1.0.1] - 2026-11-20
### Добавлено
- Диалог привязки резервного копирования в Google Drive при первом запуске (включая привязку файла через системный проводник Android без настройки Google Cloud).
- Автоматическая фоновая синхронизация с задержкой 30 секунд после изменений задач.
- Активирован GitHub Actions workflow `.github/workflows/android-release.yml`.

## [1.0.0] - 2026-11-20
### Добавлено
- Полноценное нативное Android-приложение на Kotlin + Jetpack Compose + Material Design 3.
- Светлая, тёмная и системная темы, компактный и расширенный режим карточек.
- Вертикальная Kanban-лента со сворачиваемыми статусами, свайпами, мультивыбором и массовыми действиями.
- Быстрое создание задач (нижняя строка + BottomSheet с режимом «И ещё»).
- Полнотекстовый поиск (название, описание, комментарии, заказчик), комбинируемые фильтры и сортировки.
- Справочник заказчиков, архив, корзина, статистика, экспорт JSON/CSV и импорт JSON.
- Offline-First база Room и двусторонняя синхронизация с Google Drive (OAuth 2.0, tombstones, разрешение конфликтов, проверка SHA-256).
- Локальные напоминания через WorkManager с настраиваемыми и пользовательскими интервалами.
- Проверка обновлений через GitHub Releases API с проверкой SHA-256.
- Виджет главного экрана Android.
