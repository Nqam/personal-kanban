# История изменений (Changelog)

## [1.0.22] - 2026-11-27
### Исправлено
- Планирование напоминаний переведено с `WorkManager` на `AlarmManager` (`setExactAndAllowWhileIdle` / `setAndAllowWhileIdle` + `ReminderAlarmReceiver`), чтобы Android/One UI не откладывал уведомления на несколько часов в режиме Doze.
- При запуске приложения все активные напоминания автоматически перепланируются через `AlarmManager`.

## [1.0.21] - 2026-11-22
### Улучшено и согласовано
- Убран статус «На проверке» из всего приложения (создание, детали, карточка, фильтры) — теперь везде используются единые 3 статуса: «К выполнению», «В работе», «Выполнено».
- Задачи с прежним статусом «На проверке» автоматически переводятся в «В работе» без потери данных.

## [1.0.20] - 2026-11-22
### Оптимизация и UX
- Из верхних фильтров убран статус «На проверке» (оставлены «К выполнению», «В работе», «Выполнено»).
- Настройки переработаны в компактное списковое меню: каждый раздел открывается на отдельной странице (4 кнопки быстрого доступа — Архив/Корзина, Заказчики, Тематики, Статистика — оставлены сверху).
- Отключены анимации переходов между экранами (`EnterTransition.None` / `ExitTransition.None`) — переключение страниц стало моментальным.
- Оптимизация памяти и батареи: `ThreadLocal<SimpleDateFormat>` вместо аллокаций при прокрутке, `inJustDecodeBounds` + `RGB_565` для миниатюр фото, периодическая синхронизация раз в 12 часов.

## [1.0.19] - 2026-11-22
### Улучшено и изменено
- Оставлены только 4 основных статуса и 4 фильтра на верхней панели: «К выполнению», «В работе», «На проверке», «Выполнено» (повторное нажатие на активный фильтр показывает все задачи; старые статусы автоматически мигрируют без потери данных).
- Просроченные задачи выделяются чёткой красной рамкой (`1.5dp`).
- Все новые задачи по умолчанию создаются в статусе «К выполнению».
- В статистике под датой сверху теперь всегда отображается счётчик просроченных задач (`Просрочено: N`).

## [1.0.18] - 2026-11-22
### Улучшено
- При наличии обновления в GitHub Releases при запуске приложения сразу открывается pop-up окно с кнопкой «Перейти к обновлению» (переносит прямо к разделу обновлений в Настройках).
- Улучшена перезапись привязанного файла резервной копии (`wt` с fallback на `w`), чтобы при сохранении обновлялся один и тот же файл, а не создавался новый.

## [1.0.17] - 2026-11-22
### Улучшено
- Сделана заметная разница между компактным и обычным режимами карточек: в компактном режиме уменьшены отступы и скрыты избыточные бейджи (приоритет текстом, заказчик, тематика, метки, описание), чтобы на экране помещалось значительно больше задач.

## [1.0.16] - 2026-11-21
### Обновлено
- Новое лаконичное название приложения и виджета: **TaskFlow**.
- Обновлённый минималистичный адаптивный логотип с градиентным фоном и эмблемой потока задач.

## [1.0.15] - 2026-11-21
### Добавлено
- Автоматическое перемещение выполненных задач в раздел «Старые / Архив» через 7 дней после завершения (`autoArchiveOldCompletedTasks` при запуске приложения).
- Кнопка быстрого перехода в «Старые задачи и корзина» добавлена прямо в шапку главного экрана, а в списке архива отображается дата завершения.

## [1.0.14] - 2026-11-21
### Исправлено и улучшено (по итогам ревью релиза)
- Исправлена потеря несохранённых правок названия/описания/заказчика/тематики на экране деталей задачи при переключении статуса, приоритета, меток или напоминаний (`currentDraftTask()`).
- Добавлена колонка `Epic` (Тематика) в экспорт CSV и автоматическое восстановление справочника тематик/заказчиков при импорте дампа JSON.
- На карточке задачи бейдж статуса стал кликабельным: позволяет сменить статус в 1 нажатие без открытия карточки.
- На главном экране добавлена плашка «Применены дополнительные фильтры · Сбросить» при активных фильтрах.

## [1.0.13] - 2026-11-21
### Исправлено
- Логика определения просрочки (`isOverdue`): если у задачи задана только дата (без точного времени), она считается просроченной только на следующий день; если задано время — сразу после превышения указанного времени.
- Кнопка «Сегодня» в окне быстрого создания устанавливает конец дня (`23:59`) без преждевременной пометки «Просрочено».

## [1.0.12] - 2026-11-21
### Улучшено и проверено
- Добавлена вертикальная прокрутка в панель «Фильтры и сортировка» (чтобы все статусы, тематики, заказчики и кнопка «Применить» помещались на любом экране).
- Иконка фильтра в шапке подсвечивается основным цветом при активных фильтрах.
- Добавлены unit-тесты для проверки согласованности всех 5 статусов и всех вкладок фильтрации.

## [1.0.11] - 2026-11-21
### Исправлено
- Добавлены вкладки «Ожидает» и «Запланировано» в верхнюю панель фильтров (с цветами соответствующих статусов).
- Добавлен фильтр по всем статусам (включая «Ожидает») в панель «Фильтры и сортировка».

## [1.0.10] - 2026-11-21
### Добавлено и исправлено
- При нажатии «Сохранить изменения» на экране подробностей задачи происходит возврат на главный экран.
- Добавлен раздел «Тематики (Эпики)» по аналогии с эпиками в Jira: создание/управление тематиками, автоподсказки ранее введённых тематик при создании и редактировании задач, бейдж тематики на карточке, поиск и фильтр по тематике.
- Добавлена миграция базы Room `v2 -> v3` без потери существующих задач.

## [1.0.9] - 2026-11-20
### Добавлено

- Безопасное копирование вложений во внутреннее хранилище приложения (`files/attachments/`) с миграцией базы Room `v1 -> v2` без потери данных.
- Миниатюры для фото, открытие файлов штатным просмотрщиком Android через `FileProvider`, удаление вложений и индикатор количества вложений на карточке задачи.

## [1.0.0] - 2026-11-20
### Добавлено
- Полноценное нативное Android-приложение на Kotlin + Jetpack Compose + Material Design 3.
- Светлая, тёмная и системная темы, компактный и расширенный режим карточек.
- Вертикальная Kanban-лента со сворачиваемыми статусами, свайпами, мультивыбором и массовыми действиями.
- Быстрое создание задач (нижняя строка + BottomSheet с режимом «И ещё»).
- Полнотекстовый поиск (название, описание, комментарии, заказчик), комбинируемые фильтры и сортировки.
- Справочник заказчиков, архив, корзина, статистика, экспорт JSON/CSV и импорт JSON.
- Offline-First база Room и двусторонняя синхронизация с Google Drive (OAuth 2.0, tombstones, разрешение конфликтов, проверка SHA-256).
- Локальные напоминания через WorkManager с настраиваемыми и пользовательскими интервалами.
- Проверка обновлений через GitHub Releases API с проверкой SHA-256.
- Виджет главного экрана Android.
