# Personal Kanban (Android / Samsung Galaxy S26 Ultra)

Мобильный персональный менеджер задач и бэклога в стиле минималистичного Kanban, спроектированный для быстрого повседневного использования одной рукой.

## Основные возможности
- **Быстрый ввод одной рукой**: нижняя панель быстрого ввода + BottomSheet с фокусом на «Что нужно сделать?», сохранением в 1 нажатие и режимом «И ещё» для серии задач.
- **Мобильный Kanban**: вертикальная лента карточек со сворачиваемыми статусами (`Входящие`, `Запланировано`, `В работе`, `Ожидает`, `Готово`), свайпами (вправо — завершить, влево — в корзину, с отменой), контекстным меню и массовыми операциями.
- **Полная карточка задачи**: 4 уровня приоритета, сроки (дата + время), заказчики с автодополнением и справочником, метки, хронологические комментарии (добавление, редактирование, удаление), дублирование, архив и корзина.
- **Поиск, фильтрация и сортировка**: поиск по названию, описанию, комментариям и заказчикам; комбинируемые фильтры и сортировки.
- **Offline-First + Google Drive**: локальная база Room как основной источник данных; двусторонняя синхронизация с Google Drive (папка `PersonalKanban`, версионированный JSON, tombstones для удалений, разрешение конфликтов, история снапшотов, проверка целостности SHA-256).
- **Умные напоминания**: выбор нескольких интервалов (от 15 минут до недели) + пользовательский интервал, быстрые действия в уведомлении («Открыть», «Выполнено», «Отложить 30м»).
- **Автообновление через GitHub Releases**: фоновая проверка новых версий, загрузка APK с прогрессом, проверка SHA-256 и установка штатным установщиком Android.
- **Виджет главного экрана и экспорт**: виджет с задачами на сегодня и кнопкой `+ Задача`; экспорт/импорт JSON и экспорт CSV.

## Установка на Samsung Galaxy S26 Ultra
1. Скачайте последний `PersonalKanban-release.apk` из раздела [Releases](../../releases).
2. Откройте файл на смартфоне и при необходимости разрешите установку из этого источника («Установка неизвестных приложений»).
3. Установите приложение. При первом запуске выдайте разрешение на уведомления (для напоминаний).

## Подключение Google Drive
Подробная инструкция по настройке OAuth 2.0 Client ID для вашего ключа подписи находится в [docs/GOOGLE_DRIVE_SETUP.md](docs/GOOGLE_DRIVE_SETUP.md).

## Публикация новых версий
1. Обновите `versionCode` и `versionName` в `app/build.gradle.kts` и добавьте запись в `CHANGELOG.md`.
2. Создайте и отправьте тег:
   ```bash
   git tag v1.0.1
   git push origin v1.0.1
   ```
3. GitHub Actions автоматически прогонит тесты, соберёт APK, посчитает SHA-256 и опубликует релиз.
